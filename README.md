## 🚀 Activation de GitHub Pages
1. Allez dans l'onglet **Settings** du dépôt.
2. Cliquez sur **Pages** dans le menu de gauche.
3. Sous **Build and deployment > Branch**, sélectionnez `main` et `/ (root)`.
4. Cliquez sur **Save**.
